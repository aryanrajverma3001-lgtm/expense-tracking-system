# Expense Tracking System

A web-based personal finance management application that helps users manage budgets, track expenses, and visualize spending patterns through an interactive dashboard.

## Features

* User Registration and Login using Firebase Authentication
* Budget Management
* Add, View, and Delete Expenses
* Expense Categorization
* Expense History Tracking
* Budget Remaining Calculation
* Category-Based Expense Filtering
* Interactive Charts and Analytics using Chart.js
* Responsive User Interface using Bootstrap

## Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap 5
* Firebase Authentication
* Chart.js

## Project Structure

```text
index.html       - Landing Page
login.html       - User Login
register.html    - User Registration
dashboard.html   - Expense Dashboard
css/             - Styling Files
js/              - Application Logic
```

## How to Run

1. Clone the repository:
   git clone https://github.com/yourusername/expense-tracker-system.git

2. Open the project folder.

3. Configure Firebase credentials in the project.

4. Run the application using a local server.
